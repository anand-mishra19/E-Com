# 👟 E-Commerce Sneaker Website

A modern and responsive **Sneaker E-Commerce Website** built using HTML, CSS, and JavaScript.
This is a front-end project to showcase product listings, interactive UI, and basic shopping cart functionality.

## 📝 Description

This project simulates an online sneaker store where users can:

* Browse sneaker collections
* View product details
* Add sneakers to the shopping cart
* See cart total and quantity
* Responsive design for mobile, tablet, and desktop devices

Great for learning front-end web development concepts and UI design!

## 🎨 Features

* Responsive homepage with featured products
* Product listing grid with hover effects
* Product detail modal/pop-up
* Add to cart functionality using JavaScript
* View and update cart (add/remove items)
* Smooth animations and transitions
* Simple and clean modern UI

## 🛠️ Tech Stack

* **HTML5**
* **CSS3** (Flexbox, Grid, Media Queries)
* **Vanilla JavaScript (ES6)**
* No external frameworks used (optional: Bootstrap, GSAP for animations)
